t[AI]f thinking

How I take an AI product from a problem to a first working version.

  1. Define the problemWho has it, what they need answered, and what a useful first version must do.
  2. Check the data firstAudit the data, compare a simple baseline with the model, then go, change course, or stop.
  3. Ship a small versionKeep the scope tight. CarDeal's first version takes four inputs and gives one clear answer.
  4. Build it to growClean architecture, tests, Docker and CI/CD, so the next version is easy to add.
